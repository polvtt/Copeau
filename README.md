# Copeau

Historique du presse-papiers et pinboards pour macOS.
Tout reste sur le Mac : pas de synchronisation, pas de statistiques d'usage, pas de réseau
(sauf aperçus de liens, désactivés par défaut).

## Utilisation

**⇧⌘V** ouvre le panneau en bas de l'écran (raccourci modifiable dans les réglages).

| Touche | Action |
|---|---|
| taper | rechercher (sans casse ni accents) |
| ← → | carte précédente / suivante ; ⌘← ⌘→ : première / dernière |
| ↩ | coller dans l'app active |
| ⇧↩ (ou ⌥↩) | coller en texte brut |
| ⌘1 … ⌘9 | coller la n-ième carte (⇧⌘n : texte brut) |
| Espace | aperçu agrandi |
| ⇥ / ⇧⇥ | onglet suivant / précédent (Historique, pinboards) |
| ⌘C | copier sans coller |
| ⌘⌫ | supprimer |
| ⌘R / ⌘E | renommer / modifier le texte |
| ⌘N | nouvel élément texte |
| ⌘O | ouvrir le lien |
| ⌘, | réglages |
| ⎋ | effacer la recherche, puis fermer |

À la souris : double-clic pour coller, clic droit pour le menu (épingler, renommer,
supprimer…), glisser une carte vers une autre app ou sur un onglet de pinboard. La
molette fait défiler carte par carte, et le bord supérieur du panneau sert à changer
sa hauteur.

Le menu de la barre des menus donne les 9 éléments récents, la pause de la capture,
« Ignorer la prochaine copie » et les réglages.

## Autorisations

- **Presse-papiers** (macOS 15.4+) : à la première copie, macOS peut demander si
  Copeau peut lire le presse-papiers. Il faut répondre **Toujours autoriser**
  (Réglages > Confidentialité et sécurité > Coller depuis d'autres apps).
- **Accessibilité** : nécessaire pour simuler ⌘V dans l'app cible. Sans elle, Copeau
  copie l'élément et affiche « ⌘V pour coller ».

La signature stable (identité « Flick Dev », voir `.signing.env`) fait survivre
l'autorisation aux recompilations.

## Ce qui est ignoré

- Contenus marqués transitoires ou masqués (`org.nspasteboard.ConcealedType`,
  `TransientType`, `AutoGeneratedType`…), ce que font les gestionnaires de mots de passe.
- Apps ignorées par défaut : Mots de passe, Trousseau d'accès, 1Password, LastPass,
  Dashlane, Bitwarden, Enpass, Partage d'écran (liste éditable).
- Types ajoutés par l'utilisateur ; données de plus de 64 Mo par type.

L'historique expire selon le réglage (1 jour, 1 semaine, 1 mois par défaut, 1 an,
illimité). Les éléments épinglés n'expirent pas. Le dossier de données est exclu de
Time Machine, et le panneau est masqué des partages et captures d'écran (réglable).

## Build

```bash
./build.sh                      # compile, empaquette, signe, vérifie
open build/Copeau.app           # toujours via open (autorisations TCC)
build/Copeau.app/Contents/MacOS/Copeau --snapshot /tmp/snap   # rendus PNG, données fictives
open build/Copeau.app --args --demo                          # app avec données fictives en mémoire
/usr/bin/log stream --predicate 'subsystem == "com.polat.copeau"'
```

Démarrage automatique : Réglages de Copeau > Général.

## Architecture

| Fichier | Rôle |
|---|---|
| `Core/ClipboardMonitor.swift` | scrute `changeCount` (0,4 s), laisse l'app source finir d'écrire (0,15 s), filtre, lit tous les types |
| `Core/Classifier.swift` | texte, lien, couleur, image, fichiers ; empreinte SHA-256 pour les doublons ; vignettes ImageIO |
| `Core/Store.swift`, `Database.swift` | SQLite (métadonnées) + un plist binaire par élément (données brutes) dans `~/Library/Application Support/Copeau` |
| `Core/Colleur.swift` | réécrit tous les types sur le presse-papiers, simule ⌘V avec le code de touche de la disposition courante |
| `Core/HotKey.swift` | raccourci global Carbon (`RegisterEventHotKey`), sans autorisation |
| `App/PanelController.swift` | `NSPanel` non activant au-dessus du Dock, fond `NSGlassEffectView`, animations, clavier et molette |
| `App/PanelView.swift`, `CardView.swift`, `PreviewView.swift` | interface SwiftUI |
| `App/SettingsView.swift` | réglages, enregistreur de raccourci, ouverture de session (`SMAppService`) |
| `App/Snapshot.swift` | rendus hors écran pour vérifier l'interface sans enregistrement d'écran |

Données : `items(id, kind, created, last_used, title, text, app_bundle, app_name, pinboard, checksum, meta)`
et `pinboards(id, name, color, ord)`. Un élément épinglé reste visible dans l'historique.
